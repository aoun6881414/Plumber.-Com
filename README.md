# LocalFlow Plumbing — React + Tailwind demo

## Run
1. Install Node.js 18+.
2. In this folder run:
   npm install
   npm run dev
3. Open the local URL shown by Vite.

## Build
npm run build

## API
The city search uses the public Nominatim/OpenStreetMap geocoding endpoint for an end-user initiated lookup. Do not bulk-query it or use it for systematic city/POI harvesting. For production/bulk use, use a compliant commercial geocoding/places provider or your own infrastructure.
